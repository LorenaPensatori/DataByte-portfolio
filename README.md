# DataByte-portfolio
**Quality Assurance — DataByte Academic Project**

As part of a three-member development team, I contributed to DataByte, a collaborative academic software project focused on urban waste management.

Our team worked on functional validation, test case documentation, black-box and white-box testing, test data preparation, and API testing.

The project gave me practical exposure to software quality assurance, requirements analysis, expected versus actual results, and identifying inconsistencies in software behavior.
